# Tic-Tac-Toe AI (Minimax) - Web App

This is a web-based Tic-Tac-Toe game where you play against an unbeatable AI built using the Minimax algorithm.

## 🚀 Features
- AI with perfect decision-making
- Web app UI using Streamlit
- Easy to deploy and play

## 🧠 Tech Stack
- Python
- Streamlit

## 🛠 Run Locally
```bash
pip install streamlit
streamlit run app.py
